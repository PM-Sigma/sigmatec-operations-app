# מדריכי שימוש

חמישה מדריכים קצרים בעברית לפעולות היומיומיות באפליקציה. כל מדריך מסביר מה הפעולה עושה, למי היא מיועדת, איך מבצעים אותה צעד אחר צעד (במחשב ובטלפון), מה מקבלים בסוף, ומה הטעויות הנפוצות.

1. [סיכום ביקור](סיכום-ביקור.md) — מילוי סיכום ביקור בקיבוץ בחמישה פרקים קצרים
2. [תעודת משלוח](תעודת-משלוח.md) — הפקת תעודת משלוח על ציוד שנמסר
3. [דיווח רעיון או באג](דיווח-רעיון-באג.md) — שליחת רעיון, תקלה או שיפור מתוך האפליקציה
4. [שיבוץ ביומן](שיבוץ-ביומן.md) — שיבוץ משימות EMS ליום מסוים וסידור מסלול היום
5. [תיעוד נוכחות](תיעוד-נוכחות.md) — סימון סוג היום ומעקב אחרי ימים חסרים

המסכים באפליקציה החיה: https://pm-sigma.github.io/sigmatec-operations-app/
