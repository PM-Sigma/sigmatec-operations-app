**Goal:** the closed kibbutz card is redesigned edge to edge in the section order עידן set, and the legacy
kibbutz modal (`index.html:613-852` meetings part + `js/src/10-activity.js openEditModal`) is replaced by one React
sheet, `KibbutzDetail`, with two tabs (מצב הקיבוץ / ביקורים). The ביקורים tab's content belongs to package V.

**Architecture:** one new lazy island `#sigma-kibbutz-detail` (`app/src/islands/KibbutzDetail.tsx`) opened through one
door, `sigma.openKibbutzModal(name, tab)`, which every caller already uses or is moved to. The status tab is built
from the existing panel components (EmsTasks, InternalTasksPanel, MeetingTimeline, HealthStrip, OnboardingProgress),
re-laid on the Phase 2 primitives (SectionBlock, ListRow, Tag, IconBubble, SegmentedControl, Sheet). The four
per-modal islands (ModalMeetings, InternalModal, Health, the burns modal root) and their `data-kibbutz` slot contract
(`lib/modalSlot.ts`) are deleted. Pure logic (section order, the last-visit line, the burns project line, the door)
ships first, with goldens.

**Tech stack:** React 18 + TanStack Query + Radix (shadcn files we own) + lucide-react + Tailwind mapped to `--s-*`
tokens; legacy `js/src/*.js` concatenated by `node build.mjs`; vitest; node `test-*.mjs` runners; Playwright (4
projects + the `mobile-360-light` project and `no-overlap.spec.ts` that land with Phase 2).

**Spec (binding inputs):** `docs/superpowers/specs/2026-09-23-round-5-design.md` (package table row K, rulings
"Closed card", "Burns", "Onboarding", grill round 2 "Σ = home"), `docs/superpowers/specs/2026-09-23-design-system-design.md`,
`docs/design/tools-and-motion.md`, עידן's QA list "קיבוצים 1–6" (quoted in the requirement map below), the OPS GRAPH
(`docs/ops-graph/graphify-out/RETIREMENT_MAP.md` § "Legacy kibbutz modal"). Sister plan:
`docs/superpowers/specs/2026-09-23-r5-V-visit.md` (read its "K↔V boundary", which is identical to the one here).

## Global constraints (copied from the binding specs)
- Never modify any repo other than this one.
- Edit `js/src/*.js` and `app/src/**`, then `node build.mjs`. Never edit `js/app.js` or `ui/*.js` by hand.
- Worktree off `origin/main`, branch `feat/r5-K-<task>`; the parallel-safe merge loop in `CLAUDE.md` before every push.
- Boot chunk `ui/sigma.js` stays ≤ 303 kB (150 bytes of headroom at planning time). KibbutzDetail is a **lazy** chunk;
  nothing K adds may land in the boot chunk.
- Tokens only (`--s-*`): no raw hex, px radii, z-index values or durations outside `tokens.css`/`styles.css`.
- `position:absolute` only for: a badge on its own bubble, the grab handle, a focus ring.
- Logical properties only (`inset-inline-*`, `margin-inline-*`).
- Copy: gender-neutral noun-form buttons (שמירה, סגירה…), no `!`, no em dash, no emoji in UI text (lucide icons),
  geresh/gershayim, Hebrew `aria-label`s, dates `d.m` (+`.yy` only for another year) inside `<bdi>` with `tabular-nums`.
  Gate: `test-copy-rules.mjs`.
- One primary (gradient) action per screen; an action row holds at most 3 bubbles; a meta line at most 3 tags, then `+N`.
- Motion only from `--s-motion-*` / `lib/motion.ts`; sheet enter 280 ms `--s-ease-out`, exit 180 ms `--s-ease-in`;
  list entrance only on first data render; reduced motion = opacity only.
- Burns never appear on a kibbutz card, closed or open.
- Onboarding shows only inside the open card, under מצב הקיבוץ.
- The customer code lives only in the open card (muted, `<bdi>#code</bdi>`).

## Review focus (failure modes no single task's test would naturally hit)
1. **A kibbutz whose name needs escaping** (`"`, `'`, `—`, e.g. `יגור — רפת`): the door must find it by name, not by a
   CSS selector. Pinned in K-L3 (`test-kibbutz-door.mjs` case D4).
2. **The door is called before the lazy chunk has landed** (tap in the first second, push deep link): the call must be
   queued and replayed once the island mounts, never dropped and never falling back to the deleted modal after K-U5.
   Pinned in K-L3 (D5) and K-U1 (Playwright "early open").
3. **Two opens in a row for different kibbutzim** (tap card A, close, tap card B fast): the sheet must show B's data only,
   no flash of A. Pinned in K-U1.
4. **Viewer and מתניה/אבצן/אליה** (non-admin roles): no ✏️, no adders, no burns; the sheet must not render an empty
   section title. Pinned in K-U2 (role matrix).
5. **A kibbutz with nothing** (no EMS site, no tasks, no visits, no meetings): every section shows its EmptyState line,
   not a blank block and not a missing title. Pinned in K-U2 (empty fixture).

// Package K (round 5): the pure half of the kibbutz card and KibbutzDetail. Order rulings: QA קיבוצים 3 (closed)
// and 4 (open). lastVisitLine is the TS port of js/src/10-activity.js LASTVISIT-PURE (deleted in K-U5), with the
// round-5 copy rules: no emoji, no "!", d.m dates.
export type CardSection = 'ems' | 'internal' | 'lastVisit' | 'meetings';
export type DetailSection = 'ems' | 'internal' | 'lastVisitReport' | 'meetings' | 'status';
export type DetailTab = 'status' | 'visits';

export const CLOSED_CARD_SECTIONS: readonly CardSection[] = ['ems', 'internal', 'lastVisit', 'meetings'];
export const OPEN_CARD_SECTIONS: readonly DetailSection[] = ['ems', 'internal', 'lastVisitReport', 'meetings', 'status'];

export function detailTabKey(tab?: string): DetailTab {
  return tab === 'visit' || tab === 'visits' ? 'visits' : 'status';
}

export interface VisitRow {
  id: string; kibbutz: string; date: string; visitor: string;
  duration?: number; workday?: boolean; contact?: string;
  products?: Array<{ name: string; qty?: number } | string>;
  productsOther?: string; summary?: string; openItems?: string; open_items?: string; createdAt?: string;
}

const CLOSED = new Set(['done', 'rejected', 'not_relevant', 'cancelled']);

function dayOf(s?: string): Date | null {
  const m = /^(\d{4})-(\d{2})-(\d{2})/.exec(String(s || ''));
  if (m) return new Date(+m[1], +m[2] - 1, +m[3]);
  const d = new Date(String(s || ''));
  return isNaN(d.getTime()) ? null : new Date(d.getFullYear(), d.getMonth(), d.getDate());
}
// Visit dates are stored as noon-local ISO (e.g. 09:00Z); the calendar day is the LOCAL day of that instant.
function localDay(iso?: string): Date | null {
  const d = new Date(String(iso || ''));
  return isNaN(d.getTime()) ? dayOf(iso) : new Date(d.getFullYear(), d.getMonth(), d.getDate());
}

export function fmtDay(d: Date, now: Date): string {
  const base = d.getDate() + '.' + (d.getMonth() + 1);
  return d.getFullYear() === now.getFullYear() ? base : base + '.' + String(d.getFullYear()).slice(2);
}

export function latestVisitFor(visits: VisitRow[], kibbutz: string): VisitRow | null {
  let best: VisitRow | null = null;
  for (const v of visits || []) {
    if (!v || v.kibbutz !== kibbutz || !v.date) continue;
    if (!best || new Date(v.date) > new Date(best.date)) best = v;
  }
  return best;
}

export interface LastVisitLine { label: 'ביקור אחרון'; date: string; late: boolean; note?: 'ללא סיכום ביקור' }

export function lastVisitLine(
  visit: VisitRow | null,
  tasks: Array<{ status?: string; expectedCompletionDate?: string }>,
  now: Date,
): LastVisitLine | null {
  const today = new Date(now.getFullYear(), now.getMonth(), now.getDate());
  const visitDay = visit?.date ? localDay(visit.date) : null;
  let oldestDue: Date | null = null;
  for (const t of tasks || []) {
    if (!t || CLOSED.has(String(t.status))) continue;
    const due = dayOf(t.expectedCompletionDate);
    if (!due || !(due < today)) continue;
    if (!oldestDue || due < oldestDue) oldestDue = due;
  }
  if (oldestDue && (!visitDay || visitDay < oldestDue)) {
    return { label: 'ביקור אחרון', date: fmtDay(oldestDue, now), late: true, note: 'ללא סיכום ביקור' };
  }
  return visitDay ? { label: 'ביקור אחרון', date: fmtDay(visitDay, now), late: false } : null;
}

export interface LastVisitReport {
  date: string; hours: string; visitors: string; contact?: string;
  products: string[]; productsOther?: string; summary?: string; openItems?: string;
}

export function lastVisitReport(v: VisitRow, now: Date): LastVisitReport {
  const d = localDay(v.date);
  const products = (v.products || []).map(p =>
    typeof p === 'string' ? p : (p.qty && p.qty > 1 ? `${p.name} ×${p.qty}` : p.name));
  const out: LastVisitReport = {
    date: d ? fmtDay(d, now) : '',
    hours: v.workday ? 'יום עבודה' : `${v.duration ?? 0} ש׳`,
    visitors: v.visitor || '',
    products,
  };
  if (v.contact) out.contact = v.contact;
  if (v.productsOther) out.productsOther = v.productsOther;
  if (v.summary) out.summary = v.summary;
  const open = v.openItems || v.open_items;
  if (open) out.openItems = open;
  return out;
}

```ts
import * as React from 'react';
import { sigma, sigmaBus } from '@/bridge';
import type { VisitRow } from '@/lib/kibbutzDetail';

export function visitsForKibbutz(all: VisitRow[], kibbutz: string): VisitRow[] {
  return (all || []).filter(v => v && v.kibbutz === kibbutz && v.date)
    .sort((a, b) => String(b.date).localeCompare(String(a.date)));
}

/** A kibbutz's visits, newest first. Re-reads on `visit-saved` (emitted by saveVisitFromData). */
export function useKibbutzVisits(kibbutz: string): VisitRow[] {
  const read = React.useCallback(
    () => visitsForKibbutz(((sigma as any)?.loadAllVisitsCombined?.() || []) as VisitRow[], kibbutz), [kibbutz]);
  const [rows, setRows] = React.useState<VisitRow[]>(read);
  React.useEffect(() => {
    setRows(read());
    const on = () => setRows(read());
    const bus = (window as any).sigmaBus || sigmaBus;
    bus?.addEventListener?.('visit-saved', on);
    return () => bus?.removeEventListener?.('visit-saved', on);
  }, [read]);
  return rows;
}
```
