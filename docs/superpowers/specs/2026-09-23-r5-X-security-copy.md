**Goal:** Close the open security gaps: the viewer can still write, and messages and hours aren't limited to their owner. Send visit-summary alerts only to the people who visited. Rewrite every push text in a warm, plain voice. Remove the Ctrl+K command bar without losing the two things hiding inside it. Ship an alert matrix that a golden test keeps honest.

**Architecture:** Identity moves server-side. `ems-auth` resolves the EMS user to a person from a small `staff_identities` table and mints the pass with a top-level `name` claim. That's the claim spelling every existing policy already reads (`auth.jwt() ->> 'name'`), so no policy rewrite is needed for the ones already written. Person-scoped policies for `messages` / `work_sessions` go in one new SQL file, applied only after every live pass carries the claim. The visit-alert rule is one pure function in `field.ts` (byte-mirrored into push-send). The matrix is generated by hand once and then pinned by a test that re-derives modes, recipients and tap actions from the code.

**Tech Stack:** Supabase (Postgres RLS, Edge Functions on Deno, djwt), React islands, vitest, root `test-*.mjs` runners.

## 9. Risks

1. **Locking staff out.** If a staff pass lacks `name` when `rls_person_scoped.sql` lands, that person loses messages and can't write the timer. Mitigated by the identity precheck, the 180-minute wait and the rollback block (X-L3).
2. **EMS `/users` returns 403 for non-admins**, so identity learning can't run for everyone. Mitigated by the one-time seed with עידן's token; learning is only for later hires.
3. **The byte-identical mirrors.** Three files have push-send copies. Forgetting a `cp` fails `test-field.mjs` / `test-inventory-alerts.mjs`, which is intended.
4. **CommandBar hides live features** (F1). Deleting it without moving `MessageSheet` and `runAdd` breaks messaging and the header ➕. X-L7's tests pin both before the delete.
5. **Two packages touch the header and the home chips** (S's `HeaderActions.tsx`, K's `FilterChips.tsx`). X edits those lines only if they still exist when X rebases.
6. **Timing of the matrix vs G.** Check 6 of the matrix test turns on only when `pushLog.ts` exists, so X doesn't block on G, and G's labels can't drift once it lands.
