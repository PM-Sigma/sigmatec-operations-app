STATUS: 🟡 OPEN, planned 23.9, NOT built. Resume: start at Task L1. The L tasks can start now; the U tasks wait for (a) the design-system branch `r9/DS` merged to `origin/main` and (b) the designer's PASS on the DS foundation. Order in the round: **S ships first** (round-5 spec, "Order: S → K and V → the rest").

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Use `ponytail` on every task (shortest diff, no scaffolding), TDD, and verification-before-completion.

**Goal:** One header on every page (Σ · 🔔 · ✅ · ⚙️), one page-action row under it, one bottom nav on phones and one top nav on desktop (both with ⋯ עוד), fixed chrome that reserves its own space, and toasts/offline/freshness/page motion that follow the design system, overlap-free from 360 to 3840.

**Architecture:** The shell becomes four small React surfaces built on the DS primitives: `AppHeader` (replaces the legacy `.header` markup and `HeaderActions`), `PageBar` (the page-action row, fed by `primaryAdd` + a small page-action registry), `Nav` (phone bar + desktop top tabs, both opening `MoreSheet`), and `GearSheet` (replaces the name chip). Pure rules live in `app/src/lib/shell.ts`, `pageActions.ts`, `navigate.ts`, `format.ts`, `online.ts`; the legacy side only publishes a freshness event and loses its header, desktop `.page-nav`, `#visitFab` and the floating mock notch.

**Tech Stack:** React 18 islands (`app/src`, Vite → `ui/sigma*.js`), Tailwind with `--s-*` tokens, Radix via shadcn files, lucide-react, sonner, vitest, Playwright (`qa/playwright`), legacy JS in `js/src/*.js` concatenated by `node build.mjs`.

**Spec:** `docs/superpowers/specs/2026-09-23-round-5-design.md` (package table row "S · Shell", grill rounds 1–4), `docs/superpowers/specs/2026-09-23-design-system-design.md` (§2 AppHeader, PageActionRow, Sheet, Toast; §3 overlap rules; §4 missing items 1, 7, 8, 10, 12), `docs/design/tools-and-motion.md` (§1 tools, §2 motion, §3 prestige 6–7, §4 sign-off).

## Global Constraints
- Phones 360–430 CSS px are the delivery target (360×780, 390, 412×915, 430). Desktop must hold at 1440 / 1920 / 2560 / 3840 (nightly for the last three). Foldables are out of scope; the sweep at 344 is a warning only.
- Boot chunk `ui/sigma.js` must stay `< 303 * 1024` bytes (`test-sigma-shell.mjs`). On `r9/DS` it is 310,224 bytes: **48 bytes of headroom**. Every task that touches a boot file (`main.tsx`, `Nav.tsx`, `MoreSheet.tsx`, `components/ui/sheet.tsx`, `lib/registry.ts`, `lib/landing.ts`, `bridge.ts`) must be byte-neutral or negative in the same commit.
- Tokens only: colors, radii, z-index, durations and easings come from the `--s-*` tokens (`app/src/styles.css`, tokens on `:root`). Z ladder: content 0 · sticky 10 · header 20 · nav 30 · FAB 31 · scrim 40 · sheet 50 · confirm 55 · toast 60.
- Motion tokens only: `--s-motion-press 90ms`, `--s-motion-fast 140ms`, `--s-motion-base 200ms`, `--s-motion-enter 280ms`, `--s-motion-exit 180ms`, `--s-ease-out cubic-bezier(0.16,1,0.3,1)`, `--s-ease-in cubic-bezier(0.4,0,1,1)`, `--s-ease-standard cubic-bezier(0.2,0,0,1)`, `--s-shift-md 16px`. The header and the nav bar never animate; only the nav indicator moves.
- `position:absolute` only for: a badge on its own bubble, the sheet grab handle, a focus ring. Logical properties only (`inset-inline-*`, `margin-inline-*`); physical `left`/`right` fails lint unless marked `rtl-ok`.
- Icons: lucide-react, 1.75 stroke, 20 px in rows, 24 px in the nav. No emoji in UI strings (emoji only in text people type).
- Copy: noun-form buttons (שמירה, שליחה, סגירה, ביטול, הוספה), no `!`, no em dash, geresh/gershayim (׳ ״), every icon bubble has a Hebrew `aria-label`. Gate: `test-copy-rules.mjs` against `qa/copy-rules-baseline.json`.
- Tap targets ≥ 44×44 (48 with 8 px gaps where space allows).
- Never edit `js/app.js` or `ui/*.js` by hand: edit `js/src/*.js` / `app/src/**`, then `node build.mjs`.
- Work in a worktree off `origin/main` (`git worktree add -b r5/S <path> origin/main`), rebase + rebuild before every push, ff-only (CLAUDE.md "Parallel-safe merge").
- The package does not merge without the designer's PASS (tools-and-motion §4) and a non-rising `qa/impeccable-baseline.json`.

## Review Focus
1. **A chunk that never lands.** If the header chunk fails, the static header skeleton in `index.html` must still offer Σ (go home) and ⚙️ (open settings or, failing that, `changeUser()`), so nobody is left with no way to switch user. Test pinned in Task U1.
2. **Two-digit badges at 360 with Android font scale 1.15.** 🔔 at "9+" next to ✅ at "9+" must not touch, and neither badge may leave its bubble by more than 4 px. Test pinned in Task U1.
3. **Σ for someone whose landing page is gated** (a stored `landing: 'dev'` after he lost the dev gate, or the viewer). Σ must fall back to the role default, then to קיבוצים, and never call `showPage` with a gated page. Test pinned in Task L3.
4. **Offline at boot.** A phone that opens the app with no signal must see the offline banner on the first frame the header paints, not only after an `offline` event. Test pinned in Task L5 and U7.
5. **A page change while a legacy modal or a sheet is open, or while `startViewTransition` throws.** `showPage` must run exactly once, and the view transition must never leave the page half-faded. Test pinned in Task L4.

```ts
// The one number/date formatter (tools-and-motion §3.2). Every page imports this; nobody forks it.
const NUM = new Intl.NumberFormat('he-IL');
const DAYS = ['א׳', 'ב׳', 'ג׳', 'ד׳', 'ה׳', 'ו׳', 'ש׳'];

export const fmtNumber = (n: number): string => NUM.format(n);
export const fmtUnit = (n: number, unit: string): string => `${fmtNumber(n)}\u00A0${unit}`;

export function fmtDuration(minutes: number): string {
  const m = Math.max(0, Math.round(minutes));
  const h = Math.floor(m / 60), r = m % 60;
  if (!h) return `${r} ד׳`;
  return r ? `${h} ש׳ ${r} ד׳` : `${h} ש׳`;
}

export const fmtTime = (d: Date): string =>
  `${String(d.getHours()).padStart(2, '0')}:${String(d.getMinutes()).padStart(2, '0')}`;

export function fmtDay(d: Date, now: Date = new Date()): string {
  const day = (x: Date) => new Date(x.getFullYear(), x.getMonth(), x.getDate()).getTime();
  const diff = Math.round((day(now) - day(d)) / 86_400_000);
  if (diff === 0) return 'היום';
  if (diff === 1) return 'אתמול';
  if (diff > 1 && diff <= 6) return `יום ${DAYS[d.getDay()]}`;
  const dm = `${d.getDate()}.${d.getMonth() + 1}`;
  return d.getFullYear() === now.getFullYear() ? dm : `${dm}.${String(d.getFullYear()).slice(2)}`;
}
```

```ts
// Page changes from the shell (Σ, the nav, ⋯ עוד, the back chevron). The motion lives in
// shell.css (tools-and-motion §2.2 #1–2); this only picks the kind and runs showPage ONCE.
import { sigma, type SigmaPage } from '@/bridge';
import { landingFor, roleOf, type LandingTarget } from '@/lib/landing';
import { getSettings } from '@/lib/settings';
import { canShowPage } from '@/lib/canShowPage';

export type NavKind = 'peer' | 'drill' | 'back';

const reduced = (): boolean => {
  try { return matchMedia('(prefers-reduced-motion: reduce)').matches; } catch { return true; }
};

export function go(page: SigmaPage, kind: NavKind = 'peer'): void {
  let ran = false;
  const run = () => { if (!ran) { ran = true; sigma.showPage(page); } };
  const vt = (document as any).startViewTransition as undefined | ((cb: () => void) => unknown);
  if (!vt || reduced()) { run(); return; }
  document.documentElement.dataset.nav = kind;
  try { vt.call(document, run); } catch { run(); }
}

export function goHome(): LandingTarget {
  const user = sigma.getCurrentUser?.() || '';
  const target = landingFor(roleOf(user, sigma.getRole?.()), user, getSettings(), canShowPage);
  go(target.page, 'peer');
  if (target.scrollTo) {
    setTimeout(() => document.getElementById(target.scrollTo!)?.scrollIntoView({ block: 'start' }), 80);
  }
  return target;
}

// The same "חזרה" the legacy inner pages use (02-init-attendance.js:119 `pageBack`: the page
// before this one, else the cards), so the chevron and the phone's Back agree.
export function goBack(): void {
  const pb = (window as any).pageBack;
  if (typeof pb === 'function') { pb(); return; }
  goHome();
}
```

```ts
import type { SigmaPage } from '@/bridge';
import type { PersonRole } from '@/lib/landing';
import { primaryAdd, primaryAddLabel, primaryAddOpensForm, type AddContext } from '@/lib/primaryAdd';
import { runAdd } from '@/lib/runAdd';

export interface PageAction {
  id: string; label: string; icon: string; primary?: boolean;
  onSelect: () => void; visible?: () => boolean;
}

const byPage = new Map<SigmaPage, PageAction[]>();
const listeners = new Set<() => void>();

export function registerPageAction(page: SigmaPage, action: PageAction): void {
  const list = byPage.get(page) ?? [];
  const at = list.findIndex(x => x.id === action.id);
  if (at === -1) list.push(action); else list[at] = action;
  byPage.set(page, list);
  listeners.forEach(fn => fn());
}

export function onPageActionsChanged(fn: () => void): () => void {
  listeners.add(fn);
  return () => { listeners.delete(fn); };
}

export function pageActionsFor(page: SigmaPage, role: PersonRole, ctx: AddContext = {}) {
  const add = primaryAdd(page, role, ctx);
  const label = primaryAddLabel(add);
  const all: PageAction[] = [];
  if (label) {
    all.push({ id: `add:${add}`, label, icon: primaryAddOpensForm(add) ? 'Plus' : 'ArrowLeft', primary: true, onSelect: () => runAdd(add) });
  }
  for (const x of byPage.get(page) ?? []) {
    let ok = true;
    try { ok = !x.visible || !!x.visible(); } catch { ok = false; }
    if (ok) all.push(x);
  }
  return { shown: all.slice(0, 2), overflow: all.slice(2) };
}

export function _resetPageActions(): void { byPage.clear(); listeners.clear(); }
```
