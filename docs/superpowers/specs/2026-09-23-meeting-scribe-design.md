## 1. מזכיר ישיבה חי (MeetingScribe) בתוך ▶ מצב ישיבה

**מה זה עושה.** לוחצים "🎙 מזכיר" בתחילת ישיבה. הטלפון/מחשב מקליט, כל 60 שניות הקטע מתומלל ומצטרף לתמליל
הרץ, וכל דקה נבנה סיכום מתעדכן: כותרות לפי נושא, רשימת החלטות, רשימת משימות (עם אחראי אם נאמר), שאלות פתוחות.
בסוף הישיבה: "סיים וסכם" → סיכום סופי שנכנס ל-`meeting_sessions` ומוצע לייבוא כמו סיכום ישיבה מיובא
(`ImportNotes` → מטלות פנימיות / משימות EMS לפי הקיבוץ שעליו דיברו).

**מה כבר קיים ומנוצל.**
- Edge Function `transcribe` (Whisper בשרת העצמי לפי `docs/whisper-server.md`, Groq כביטוח) עם `transcribe_log` לעלויות.
- שרשרת הניתוח `parse-daylog` (משותפת ליומן היום ולהקלטת סיכום הביקור) — הפרומפט שם כבר יודע לחלץ קיבוץ/משימה/מוצרים.
- `meeting_sessions` / `meeting_events` (Presenter) — יש איפה לשמור.
- `ImportNotes` — הופך סיכום לטקסט מובנה ולמשימות.
- `MediaRecorder` + מנגנון ההעלאה של `speech.ts` (fallback ההקלטה).

**מה בונים (3 חלקים, ~1.5 ימי סוכן).**
1. `app/src/lib/scribe.ts` (טהור): חיתוך לקטעים של 60 שניות, מיזוג תמלילים (הסרת חפיפות בין קטעים — Whisper
   מחזיר לפעמים את סוף הקטע הקודם), בניית פרומפט הסיכום המצטבר ("הנה הסיכום עד עכשיו + הדקה החדשה → סיכום
   מעודכן, כותרות/החלטות/משימות/שאלות"), הנחיות ישיבה שעידן נותן מראש (למשל "כל משימה חייבת אחראי"). goldens.
2. Edge Function `meeting-summarize` (או mode ב-`parse-daylog`): מקבל תמליל מצטבר + סיכום קודם + הנחיות, מחזיר JSON
   מובנה. אותו ספק כמו יומן היום, אין ספק חדש.
3. `MeetingScribe` island בתוך Presenter: כפתור 🎙, פס "מתמלל… דקה 7", פאנל סיכום חי (מתקפל), "סיים וסכם" → שמירה +
   הצעה לייבוא. עובד גם בטלפון (רוחב 360).

**עלות.** ~1 קריאת Whisper לדקה (חינם בשרת העצמי, אחרת ~$0.006) + ~1 קריאת LLM לדקה עם הקשר מצטבר (~$0.01–0.03).
ישיבה של שעה ≈ $1–2 ב-Groq/OpenAI, ~$0 עם Whisper עצמי. הפרומפט המצטבר שומר על הקשר קצר (סיכום קודם + דקה
אחרונה, לא כל התמליל).

**סיכונים ומה עושים איתם.**
- דיוק עברית ממיקרופון על שולחן: להתחיל במיקרופון של המחשב, ולהציג את התמליל הגולמי ליד הסיכום כדי שתיקון יהיה
  מהיר; המילון `docs/whisper-glossary.txt` (שמות קיבוצים, מונים) מוזרם כ-prompt ל-Whisper.
- אין זיהוי דוברים: הסיכום לא יאמר "אמר אביאם". אם חשוב, שלב ב' עם pyannote בשרת (יום עבודה נוסף).
- פרטיות: התמלילים ב-bucket פרטי עם מחיקה אחרי 30 יום (כמו `feedback-audio`).

**הצלחה נמדדת ב:** בסוף הישיבה יש רשימת משימות שעידן מאשר ב-3 לחיצות ושהופכת למשימות פנימיות/EMS.

## 3. "מאז הישיבה הקודמת" — גם משימות EMS
ל-`EmsTask` אין חותמת פתיחה/סגירה בקאש. שתי אפשרויות:
- **זול (מומלץ):** `ems_cache` שומר snapshot כל 15 דקות; לשמור לצד ה-cache "צילום" של מזהי המשימות הפתוחות בתאריך
  כל ישיבה (`meeting_sessions.ems_open_ids jsonb`). בישיבה הבאה: הפרש קבוצות = מה נפתח / מה נסגר. אין תלות ב-EMS API.
- **מדויק:** לקרוא `createdAt`/`completedAt` מה-EMS API אם קיימים (לבדוק ב-`/tasks` שדות). אם יש — להוסיף לקאש
  ולהשוות לתאריך הישיבה הקודמת.
שעה–שעתיים סוכן.
